# Security Policy

## Supported Versions

Security fixes are provided for the latest major version of this package.

## Reporting a Vulnerability

Please report security vulnerabilities privately using [GitHub's private vulnerability reporting](https://github.com/lenorix/laravel-beel/security/advisories/new) instead of opening a public issue.

If that is not possible, email jesushdez@protonmail.com with a description of the vulnerability and steps to reproduce it. We will acknowledge your report as soon as possible and keep you updated as we work on a fix.
